## Theme synthesis (candidate ranking for the detailed retro)

1. **Shared-worktree hazards** — the largest cluster by count and cost; three directions named by mollusk: I sweep them (DL-002/037/066), they sweep me / I ship their half-work (DL-047/064), and nobody can get a trustworthy green (DL-005/034/060/068/089). Kazimir's cross-cut: five of its eleven are shared-mutable-state failures, "not one of them is a Rust problem". **Largely closed by the ruled worktree-per-coder cutover**; what remains worth building is a first-class `harness verify <sha> [--scope <crates>]` (DL-069, CONF-013 — currently a ritual each seat reinvents).
2. **No scoped gate verdict / no failure attribution** — five seats independently (DL-015+104, DL-026, DL-069, DL-076, DL-087/088): `harness checks` is all-or-nothing, first-failure-wins, and names no owning crate, so a fence-clean worker's first move is always to suspect themselves. Ask: `--fence/--scope/--only`, per-crate attribution, non-short-circuiting. **Top candidate for the upstream harness-engineering ask.**
3. **The shell eats your input, silently** — backticks command-substituted out of commit messages (DL-063: two damaged commits permanent on main; DL-044: same mechanism, different victim), plus the two-layer trap of a noise-like warning above a help line that says you are safe (DL-108). Encoding, not teaching: `harness commit -F <file>`/stdin removes the shell from the path. Cattle and sawfish's joint point: twice in one day (cp-vs-mv, backticks) the outcome turned on which character a seat's fingers happened to reach for.
4. **Shared credentials are unaccounted fleet resources** — DL-018/019: one default-interval watcher exceeds the whole fleet's API budget; rules prescribing repeated action against shared rate-limited resources must state interval+concurrency (now encoded as DL-019/fleet rule); `gh api rate_limit` is free and should gate any polling verb.
5. **Doc-vs-code drift has no failing gate** — frozen envelope vs daemon (DL-001 skunk), workshop spec vs domain invariant (DL-048 — a faithful implementation of an authoritative doc was a data-loss bug), stale doc comments across fences (DL-090/091). Ask: fixture-driven per-verb contract tests; "a verification report should name the test that would go red" (DL-092).
6. **The drain itself is lossy at its boundary** — DL-050 (an observation filed 4 min before a drain vanished unencoded, no receipt), DL-071 (all-or-nothing `--clear`), mid-session renumbering ate two seats' in-flight ids. Ask: per-id disposition receipts from the drain, per-seat buffers or append-only ids.
7. **Environment-shaped false verdicts** — cargo shim/toolchain shadowing (encoded: rust-toolchain.toml), exported env leaking across commands (DL-033/096), volume-mount and PATH traps in containers (ox's set), `/usr/bin/time -l` absolute RSS lies (CONF-009).
