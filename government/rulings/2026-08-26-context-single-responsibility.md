# Ruling — a seat's context is a first-class asset; single responsibility applies to CONTEXT
**By**: Jordan (verbatim: "These agents all have excellent context, and we don't want to pollute agents with the wrong thing… using our agent peers in a first class single responsibility thinking for their context management") · **Recorded**: 2026-08-26 · pij-instant-lynx

## The doctrine

1. **A specialist seat IS its context.** Sylac's value is not that it can code — it's that it holds the store's whole design space (every decision, rejected alternative, and trap). That asset degrades with every off-domain token fed into it.
2. **Route by context fit, not availability.** Work goes to the seat whose context already contains the domain (the roster is the directory). An idle specialist is NOT a free generalist — off-domain work goes to a FRESH SPAWN, which is cheap; a polluted specialist is expensive and unrecoverable.
3. **Briefs and fix-asks stay scoped to the seat's domain.** A fix ask to an author names their service, their files, their repro — never "while you're in there" scope creep. Deltas extend a seat's task only within its domain (kazimir: azure → structured summaries → openai-compat = same domain, deepening; kazimir → "also fix the daemon" = pollution, refused).
4. **Re-open rather than re-explain.** When domain work recurs, re-open the author seat (its context makes it 10x cheaper) instead of briefing a fresh seat into the domain — the inverse error to #2.
5. **The o-prime carries the cross-domain picture** so no worker has to: integration/composition questions terminate at the prime or the integrator seat, never by cross-briefing two specialists into each other's domains.
6. **Retire honestly.** When a domain's work is genuinely done for a long horizon, the seat's durable knowledge must already be OUT of its context — in docs/services/*, the skills, and the workshops (this is why worker-authored service pages are part of "done"). Context is a cache; the docs are the store.

## Mechanics
- Roster rows carry the domain; dispatches cite it.
- Fresh-spawn default for any new domain; author-seat default for any recurring domain.
- Sawfish's direct fix-routing (2026-08-26) operates under rule 3's scoping.
